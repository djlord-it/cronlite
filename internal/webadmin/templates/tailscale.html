Not built in

Tailscale is not built into this binary

The default build leaves Tailscale out to keep the binary small. Tailnet delivery (WEBHOOK_ALLOW_TAILNET) and tailnet access (TS_LISTEN) need a build made with the tailscale tag:

docker build --build-arg TAGS=tailscale -t cronlite:tailscale .
go build -tags tailscale -o cronlite ./cmd/cronlite

See TAILSCALE.md in the CronLite repository for the step-by-step guide.

{{else if not .Started}}

Built in · off

Tailscale is built in but not enabled

Set WEBHOOK_ALLOW_TAILNET=true (with WEBHOOK_TAILNET_HOSTS) to deliver webhooks to tailnet hosts, or TS_LISTEN=true to serve CronLite on the tailnet. Both need TS_STATE_DIR.

See TAILSCALE.md in the CronLite repository for the step-by-step guide.
